# MFTI-course-project
Итоговый проект курса "Искусственный интеллект и ИИ-агенты в бизнесе 2026" от МФТИ. Проект сгенерирован нейросетью CLAUDE на Vite vue.js. Проект представляет собой смесь тамагочи и todo листа. У питомца есть 2 шкалы "Сытость" и "Счастье" с соответствующими статусами, которые заполняются при выполнении заданий пользователем.
